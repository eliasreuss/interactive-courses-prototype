The Assign Action dialog also includes an Alert mail checkbox, separate from the subscription plan option. Ticking it sends assignees a mail whenever a new item is added to the Action list, in addition to any scheduled status subscription you set up.

Note that ticking "Subscribe all assignees to this Action" only affects assignees who are not already subscribed — anyone already subscribed keeps their existing subscription settings.
