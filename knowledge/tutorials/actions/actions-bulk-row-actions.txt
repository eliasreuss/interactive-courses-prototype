Checking one or more row checkboxes inside an open Action list switches the toolbar into bulk action mode, showing:

Deselect all (N) — clears the current selection
Delete (N) — deletes the selected items
Email icon — emails the selected items
Comment icon — adds a comment tied to the selected items
Copy icon (N) — copies the selected rows to the clipboard
Download icon (N) — downloads the selected rows

The (N) shows how many items are currently selected. After clicking Deselect all, a Select again button appears in the toolbar so you can quickly restore your previous selection.
