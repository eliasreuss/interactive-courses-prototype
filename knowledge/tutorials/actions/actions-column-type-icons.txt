In the Data Setup dialog for an Action list, each column in the Available and Included lists shows a small icon indicating its data type:

# — numeric value
Tr — text/categorical value
ID — identifier column
Calendar icon — date column

These icons help you quickly tell what kind of data a column holds before adding it to the Action list.
