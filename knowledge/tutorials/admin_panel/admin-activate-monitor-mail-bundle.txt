Each bundle in the Bundles list shows its current status. A grey Activate button means the bundle is inactive — click it to start delivery. A green Activated badge means it's running.

The Last sent column shows the most recent delivery date. The Recipients column shows the count — a yellow warning icon (⚠) next to a count of 0 means the bundle has no recipients assigned, so it won't send to anyone.

You can also filter the bundle list by frequency using the pill buttons at the top (Daily, Weekly, Monthly).
