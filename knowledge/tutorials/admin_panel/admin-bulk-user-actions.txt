Check the header checkbox to select all visible users. A bulk action bar appears at the bottom with three actions:

Set permissions for N users — opens a simplified role picker dialog to choose one role to apply to all selected users at once.
Send welcome mail to N users — re-sends the welcome/invitation email to all selected users.
Disable N users — disables all selected accounts (shown in red as a destructive action).

The "Showing N of N" counter also updates, and the copy-to-clipboard button shows the count of selected users. Use the Deselect button to clear the selection.
