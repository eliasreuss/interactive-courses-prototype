When you click + New in the table tab bar and choose Dashboard table, the "Add new Dashboard table" dialog opens with a Title field and a "Copy Columns from" dropdown. Use "Copy Columns from" to select an existing tab whose column setup you want to reuse, so you don't have to rebuild the same columns from scratch on the new tab.
