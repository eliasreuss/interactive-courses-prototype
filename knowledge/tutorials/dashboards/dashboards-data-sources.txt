Every dashboard pulls data from one or more Insights. To see exactly which ones:

1. Open the dashboard.
2. Click the small ℹ info icon next to the dashboard name in the top-left area.

A window appears showing:

Insights — a list of every Insight contributing data to this dashboard, with the type of data each one provides (e.g., Products, Customers, Suppliers).

End2End — a summary of which entity types are connected, for example: "This Dashboard is connected to Suppliers / Products / Customers."

This is useful if you're seeing unexpected numbers and want to trace them back to their source, or if you need to know which Insights need to be refreshed to keep the dashboard current.

Click OK to close.
