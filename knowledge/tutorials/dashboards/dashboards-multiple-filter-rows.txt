Multiple filter rows lets you automatically create one row for each value in a categorical column — useful when you want to break down data by category without creating rows one by one.

1. In the Table tab, click + Add row and select Multiple filter rows.
2. In the dialog, use the Select column dropdown to choose a categorical column. Only categorical columns are available — not numeric ones.
3. Once you select a column, tag pills appear showing all the values in that column. Each value will become its own row.
4. Click Save to generate all the rows at once.
