If you want to share a specific view of an Insight — with particular filters or slicers already applied — you can copy a direct link that opens the Insight in exactly that state.

1. Set up the Insight view the way you want it (apply filters, choose your view type, etc.).
2. Click the link icon (chain link) in the top-right corner of the Insight page.
3. The Share this view window appears, showing a URL and the message: "Copy a link to this view, complete with the current slicing and settings."
4. Click Copy to clipboard.
5. Paste the link wherever you want to share it — email, chat, etc.

When someone opens that link, they'll see the Insight exactly as you had it set up, including any active filters.
