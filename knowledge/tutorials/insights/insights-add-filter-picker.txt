In edit mode, a "+ Insight filter" button appears in the toolbar next to the view tabs. Clicking it opens a column picker dropdown with a search box at the top, listing all columns from the Insight's data source — not just numeric ones. Each column is shown with a type icon (# for numeric, Tr for text, ID for identifiers, and so on).

If a column already has an active filter, it's marked "Active" in the list.

Click any column name to open the Data slicer dialog for that column, where you set the filter condition and values (the available conditions differ for text versus numeric columns).
