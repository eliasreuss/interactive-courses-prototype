When editing an Insight, you can control which filters appear in the filter bar for all users of that Insight.

1. Open the Insight and turn on edit mode by clicking the gear icon.
2. Two buttons appear in the filter bar: + Insight filter and + Fixed slicer.
   - + Insight filter — adds a numeric filter. Click it to see a searchable list of available metric columns. Select one to add it as a filter that viewers can use to narrow results by value ranges.
   - + Fixed slicer — adds a category filter. Click it to see a list of categorical fields (e.g., Item Group, Product Group, Item Status, Responsible, Customer Group, Supplier Group). Select one to add it as a dropdown filter.
3. To remove a filter in edit mode, click the red × button next to it in the filter bar.

These changes affect all users of the Insight. Click Save to apply.
